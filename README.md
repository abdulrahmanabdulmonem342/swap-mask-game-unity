# 🎭 Swap Mask — Global Game Jam 2026

## 📌 Project Overview
**Swap Mask** is a 2D level-based platformer prototype designed and developed in **14 hours** during **Global Game Jam 2026** (University of Tabuk Jam Site) under the theme **"Mask"**.

---

## 🎮 Gameplay & Mechanics
* **Level Progression:** Multi-stage movement mechanics where the player controls the character through environmental challenges to collect golden coins at the end of each stage.
* **Core Controls:** Smooth 2D character movement, jump physics, and stage completion detection.

---

## 🛠️ Technical Specifications
* **Game Engine:** Unity (2D Tilemaps & Physics)
* **Programming:** C# (Player movement, coin collection logic, and scene management)
* **Development Timeframe:** Rapid 14-hour prototyping cycle during the hackathon.
